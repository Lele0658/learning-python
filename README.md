# Learning Python

A collection of beginner Python practice programs and small projects created while learning Python.

## Project Files

### hello.py

A simple practice program demonstrating basic Python syntax and output.

### quiz-app.py

A basic quiz application built with Python that demonstrates:
- Variables
- User input
- Conditional statements (`if/else`)
- Score tracking

## Getting Started

### Prerequisites

- Python 3.x installed on your computer

Check your Python version:

```bash
python --version
```

or

```bash
python3 --version
```

## Running the Programs

Clone the repository:

```bash
git clone https://github.com/Lele0658/learning-python.git
```

Move into the project folder:

```bash
cd learning-python
```

Run a program:

```bash
python hello.py
```

or

```bash
python quiz-app.py
```
